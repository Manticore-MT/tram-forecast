# Непортированные блоки старого дашборда

Старый дашборд (`frontend/src/products/forecast-dashboard/`, маршрут `/dashboard-legacy`) и макеты
вариантов карточки остановки (`frontend/src/mockups/stopDetail/`, маршрут `/mockups`) удалены из
кода. Последнее состояние сохранено под git-тегом **`legacy-dashboard`**.

Достать файл целиком:

```bash
git show legacy-dashboard:frontend/src/products/forecast-dashboard/Screens.tsx
```

Ниже — всё, чего нет в текущем продукте (`frontend/src/features/dispatcher/`), с пометкой, на
реальных данных блок или на выдуманных. Перенесли блок — вычеркни его отсюда.

| Блок | Где в теге | Данные | Зачем может понадобиться |
|---|---|---|---|
| Матрица загрузки «день недели × час» + счётчик часов с загрузкой > 80 % | `Screens.tsx` → `RouteView`, `Charts.tsx` → `Heatmap` | реальные, `GET /api/routes/{id}/load-matrix` | типичная неделя маршрута; единственное место, где используется этот эндпоинт |
| Экран «Модель»: WAPE и оценка со спарклайнами за 90 дней, полная история | `Screens.tsx` → `ModelView` | реальные, `GET /api/model/stats?days=90` | критерий 1 (качество прогноза) на демо; в «Обзоре» сейчас только WAPE и 5 последних записей |
| Долгосрочный прогноз: 12 столбиков по месяцам с подписями | `Screens.tsx` → `Overview`, панель «Долгосрочный прогноз» | реальные, `horizon=year` | горизонт «год» наглядно; частично перекрывается полосой «Время» |
| Список маршрутов сети с `LoadMeter` по прогнозу | `Screens.tsx` → `Overview`, панель «Маршруты сети» | реальные, `GET /api/routes` | сравнение маршрутов между собой без карты |
| Отклонение от базового уровня по маршрутам (двусторонние полосы ±%) | `Screens.tsx` → `Overview`, панель «Отклонение от базового уровня» | реальные, `GET /api/routes` | «где сегодня необычно» по всей сети одним взглядом |

| Выбор маршрута тегами в шапке | `Shell.tsx` → `TopBar` | — | альтернатива клику по карте |
| Кнопка экспорта CSV | `Shell.tsx` → `TopBar`, `DashApp.tsx` | **выдуманная**: показывает тост, `/api/export` не вызывает | нужна настоящая, с `GET /api/export` |
| Бренд-блок в сайдбаре (логотип, «Поток · Manticore · трек 02») | `Shell.tsx` → `Sidebar` | — | шапка продукта |
| «Учёт внешних факторов» (календарь, погода, события, ВСМ) | `Screens.tsx` → `EXTERNAL_FACTORS` | **выдуманные** тексты | критерий 2а — только с реальными источниками |

## Только в ранней версии (до подключения к API)

Эти блоки были на выдуманных данных и пропали, когда старый дашборд переводили на реальный API.
Они лежат под вторым тегом, **`legacy-dashboard-mock`**:

```bash
git show legacy-dashboard-mock:frontend/src/products/forecast-dashboard/Screens.tsx
```

| Блок | Где в теге | Зачем может понадобиться |
|---|---|---|
| Список рекомендаций диспетчеру: тон («Пик» / «Внимание» / «Резерв») + место и время + действие («добавить 2 вагона на выпуск») | `Screens.tsx` → `RouteView` | единственный явно «действенный» блок для диспетчера; реальный источник — `recommendation` в ответах API |
| Важность признаков модели (полосы «Час суток 0.94», «Погода 0.48», …) | `Screens.tsx` → `ModelView` | критерий 2 (внешние источники и их эффект), если ML отдаст реальную важность |
| История обучений: версия, дата, статус «в проде/архив», точность, кнопка «Переобучить» | `Screens.tsx` → `ModelView` | история версий модели на демо |
| Статус потока данных в сайдбаре (время последней синхронизации) | `Shell.tsx` → `Sidebar` | индикатор свежести данных |
