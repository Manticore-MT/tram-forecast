# UI kit — «Поток», дашборд прогноза загрузки (трек 02)

The dispatcher-facing web service described in the track-02 brief: short-, mid- and long-horizon passenger-load forecasts for tram routes, aggregated by route, stop and time window.

**This kit is a proposal, not a recreation.** No existing product design, Figma file or codebase was supplied for it — it is this design system applied to the written brief. Treat every layout decision here as a starting point to be checked against the real ЕДЦ workflow.

**Screens:** Карта загрузки (default) · Обзор сети · Маршрут · Модель · Данные.

**Files**
- `index.html` — mount + script order (Leaflet + React + bundle).
- `MapScreens.jsx` — `MapView` (real OSM basemap of Moscow, load-coloured stops, time scrubber, glass overlays), `IngestView` (pipelines, data quality, forecast API).
- `Charts.jsx` — `ForecastChart` (fact vs dashed forecast + confidence band), `Sparkline`, `Heatmap` (day × hour), `RouteStrip`, `seedSeries`.
- `Shell.jsx` — `Sidebar`, `TopBar` (route chips, horizon tabs, export), `Panel`, `LoadLegend`.
- `Screens.jsx` — `Overview` (KPIs + forecast + stop load + network), `RouteView` (load matrix + dispatcher recommendations), `ModelView` (metrics, feature importance, training runs).
- `DashApp.jsx` — shell composition and state.

**Interactive:** sidebar view switching, route chips, 1 день / 1 месяц / 1 год horizon tabs, confidence-interval toggle, CSV export toast.

**The map.** `MapView` renders a **real OpenStreetMap basemap of Moscow** via Leaflet (dark-filtered tiles, attribution retained), with stop markers and connector segments coloured on the shared `--load-*` scale and a 05:00–23:30 time scrubber. Stop positions are **approximate coordinates of the named landmarks** and the connectors are **straight segments, not surveyed track geometry** — an on-map note says so. Replace `GEO` in `MapScreens.jsx` with real ЕДЦ route geometry. `RouteStrip` (in `Charts.jsx`) remains as the compact non-geographic view used inside Обзор сети.

**Synthetic data.** All numbers are generated by `seedSeries` with a двухпиковый (morning/evening) shape. Nothing here is a real measurement.
