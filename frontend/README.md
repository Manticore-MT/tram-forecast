# Поток

Тёмное по умолчанию, русскоязычное React + TypeScript приложение для **Хакатона Московского транспорта** (25.09 — 03.10.2026) и продукта по треку 02 хакатона, **«ИИ-прогноз загрузки трамвайных маршрутов»**, от команды **Manticore**.

## Контекст

Хакатон проводят **фонд «Транспортные инновации Москвы»**, ИТ-компания Правительства Москвы **МТТЕХ** и **ООО «ВСМ-400»** при поддержке Департамента транспорта Москвы. МТТЕХ — центр разработки транспортных приложений, которыми ежедневно пользуются миллионы пассажиров: оплата проезда, построение маршрутов, программа беспилотного трамвая.

**«Поток» — сам продукт** (`src/features/dispatcher/`, маршрут по умолчанию в `src/App.tsx`). **Это и есть сдаваемое решение.** Сервис для диспетчера по треку 02: прогноз пассажиропотока трамваев на горизонтах день / 7 дней / месяц / год, с детализацией по маршруту, остановке и временному окну, на реальной карте Москвы. Два экрана: Диспетчер (US1-6) и Обзор сети (US7-10). Это **предложение, а не воссоздание** — готового дизайна продукта не было, поэтому бренд применён к брифу самостоятельно.

Предыдущая версия продукта (старый дашборд) удалена: полезное перенесено, а блоки, которые ждут данных, перечислены в [`../docs/open-questions.md`](../docs/open-questions.md) вместе с git-тегами, откуда достать их код.

### Чего не было — явные замены

- **Нет файлов шрифтов.** Взят **Manrope** (геометрический гротеск, полная кириллица, ближе всего к угловатой «М» логотипа) и **JetBrains Mono** для цифр. Подключены из Google Fonts в `src/styles/tokens/fonts.css`.
- **Нет цветовой спецификации.** Единственное твёрдое свидетельство — чёрно-белый логотип. Шкала оттенков чёрного выведена из него; акцентный **сигнальный красный** и пятиступенчатая шкала загрузки — предложение.
- **Нет набора иконок.** Взят **Lucide** (обводка 2 px, скруглённые концы), подтягивается по-глифно с CDN и инлайнится как настоящая SVG-геометрия, чтобы иконки наследовали `currentColor`.
- **Нет фотографий и иллюстраций.** Портреты экспертов и любые изображения отрисованы как подписанные пустые плашки — ничего не придумано.

## Запуск

```
npm install
npm run dev
```

Открыть `http://localhost:5173/` — дашборд (маршрут по умолчанию).

```
src/
  main.tsx, App.tsx        точка входа + настройка роутинга
  styles/
    index.css              единая точка входа CSS (список @import)
    tokens/                 шрифты, цвета, типографика, отступы, радиусы, elevation, motion, базовые сбросы
  assets/                   логотип, знак-булавка (SVG)
  components/               19 общих компонентов, типизированные, по категориям
    core/                   Button, IconButton, Icon, Card, Badge, Tag
    forms/                  Input, Select, Checkbox, Radio, Switch
    navigation/             Tabs, Accordion
    feedback/               Dialog, Toast, Tooltip
    data/                   Stat, LoadMeter, Timeline
  features/
    dispatcher/             ПРОДУКТ — диспетчерский дашборд «Поток», 2 экрана, настоящая карта Leaflet/OSM
```

## ОСНОВЫ КОНТЕНТА

**Язык.** Везде русский. Никаких английских строк в UI, никакой транслитерации. Латиница — только в именах собственных и технических терминах, которые аудитория и так читает латиницей: `MAPE`, `CSV`, `ML`, `Spring Boot`, `React`.

**Обращение и лицо.** Сайт обращается к читателю на **вы**, почти всегда в **повелительном наклонении множественного числа**: «Решайте реальные задачи», «Создавайте решения», «Выбирайте один трек», «Получайте обратную связь», «Вступайте в чат». Организаторы никогда не говорят о себе «мы» в заголовках — сообщение несут глаголы.

**Стиль заголовков.** Именные группы или императивы, без точки в конце, без восклицательных знаков. Заголовки разделов — одно-два простых слова: «О хакатоне», «Задачи», «Призовой фонд», «Таймлайн», «Эксперты», «Организаторы», «Ответы на вопросы» — не «FAQ».

**Метка : значение.** Факты пишутся как короткая полу-заглавная метка с голым значением под ней, никогда не предложением: «Даты / 25 сентября — 3 октября», «Формат / Онлайн с финалом в Москве», «Команда / От 3 до 5 человек».

**Числа.** Тонкий/обычный пробел как разделитель тысяч, знак валюты после числа с пробелом: `4 000 000 ₽`. У процента — пробел: `86 %`. Десятичный разделитель — точка в технических метриках (`7.4 %`, `0.91`), для процентных пунктов — «п.п.».

**Тон.** Гражданский и деловой, с масштабным акцентом — «миллионы людей», «приводит целый город в движение». Никаких хайповых прилагательных, никаких восклицаний.

**Регистр.** Везде sentence case (только первая буква заглавная). ВСЕ ЗАГЛАВНЫЕ — только для мелких «eyebrow»-подписей (`.mt-eyebrow`), никогда для заголовков или кнопок.

**Эмодзи: никогда.**

**Кавычки.** Русские «ёлочки»: «ВСМ-400», «Транспортные инновации Москвы».

## ОСНОВЫ ВИЗУАЛА

**Фон.** Тёмное по умолчанию — `--bg-page` это `#0E1113`; поверхности повышаются через `#15191C` → `#1C2226` → `#252D33`. Скоуп `[data-theme="light"]` существует только для печати/экспорта.

**Цвет.** Один главный акцент: **сигнальный красный `#F0392B`** — основные CTA, маркер «сейчас/live», достигнутые вехи таймлайна, пиковая загрузка. Используется скупо: не больше одного красного элемента на экран. **Шкала загрузки пассажиров** (`--load-1` … `--load-5`, зелёный → салатовый → янтарный → оранжевый → красный) — *единственная* разрешённая цветовая шкала загрузки. Ряды графиков — циан/синий/бирюзовый/салатовый. **Без фиолетового, без мультихью-градиентов.**

**Шрифт.** Manrope для дисплея/заголовков/UI; JetBrains Mono (табличные цифры) для всех чисел. Дисплей — начертание 800 с трекингом −0.03em, интерлиньяж меньше 1.0. Текст — 400, никогда не жирный для акцента.

**Отступы.** Сетка 4 px. Маркетинговые секции дышат на `--space-section` 96 px (в hero — 160 px); продуктовый UI никогда не превышает 32 px внутреннего паддинга. Максимальная ширина контента — 1240 px.

**Карточки.** Заливка + волосяная линия, без drop shadow. `surface` — дефолт; `raised` поднимает заливку; `glass` (6% белой заливки + блюр 16px) легален только поверх карты/графика/цветного фона; `accent` — сплошной красный; `outline` — прозрачная волосяная линия.

**Радиусы и «булавка».** Щедрые: 10 / 14 / 20 / 28 / 40 px плюс pill. `--radius-pin` (три угла по 40px, один угол 6px) — не больше чем на одном-двух hero-элементах страницы.

**Карты.** Только реальная геометрия — подложка OSM под тёмным фильтром тайлов, никогда не рисованный город. Загрузка передаётся заливкой маркера и цветом сегмента по `--load-*`.

**Визуализация данных.** Факт — сплошная линия циан 2.5px с мягкой заливкой; прогноз — **пунктирная** красная линия 2.5px; доверительный интервал — красный при 14% непрозрачности. Пунктирная вертикальная линия с подписью «сейчас» разделяет их.

**Иконки.** Lucide (обводка 1.5px, скруглённые концы), подтягиваются по-глифно и инлайнятся как настоящий SVG через `src/components/core/Icon.tsx`, чтобы глифы наследовали `currentColor`. Размеры: 14px в чипах/бейджах, 16px инлайн, 18px в кнопках/навигации, 20–24px как ведущий глиф карточки.

**Синтетические данные.** Все числа в дашборде генерируются `seedSeries` с двухпиковой (утро/вечер) формой. Ничто не является реальным измерением. Позиции остановок на карте — приблизительные координаты именованных ориентиров; соединители — прямые отрезки, не съёмка пути.
