Single icon glyph. Always inherits text colour — set colour on the parent, not the icon.

```jsx
<Icon name="tram-front" size={20} />
```

Transit-relevant names used across the kits: `tram-front`, `train-front`, `map-pin`, `route`, `users`, `calendar`, `clock`, `trophy`, `arrow-right`, `chevron-down`, `trending-up`, `activity`, `layers`, `download`, `send`.
